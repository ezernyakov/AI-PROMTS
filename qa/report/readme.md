### Алгоритм построения отчета
1. подготовить техническое задание;
2. создать mind-карту с помощью mind_map.md на основе технического задания;
3. создать таблицу эвристик с помощью heuristics.md на основе технического задания и mind-карты;
4. создать таблицу рисков с помощью risks.md на основе технического задания и mind-карты, эвристик;
5. создать шаблоны заготовленных сессий исследовательского тестирования с помощью sessions.md на основе технического задания и mind-карты, эвристик, рисков.
