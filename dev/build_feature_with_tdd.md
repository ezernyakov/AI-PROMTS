# Этап 1 - подготовка тестов
*********************************************************************************************************************************
## Роль: 
Ты — ведущий разработчик программного обеспечения, эксперт по высоконагруженным распределенным системам.

## Контекст: 
  1. Документация по системе: {<>/docs/README.md}
  2. Для изучения структуры кода используй метод Repository Planning Graph (RPG). RPG — это граф, где узлы представляют собой компоненты кода (например, классы, функции, модули), а ребра фиксируют семантические связи, потоки данных (например, импорты, вызовы, наследование). Ссылка на RPG кода тестируемого сервиса: {<>/docs/rpg/README.md}
- **ОБЯЗАТЕЛЬНО**: Используй RPG-граф для навигации по коду тестируемого сервиса. Граф содержит все компоненты (классы, функции, модули) и их связи (импорты, вызовы, зависимости).
  **Процесс**:
    1. Анализируй граф для поиска релевантных компонентов
    2. Определяй зависимости через ребра графа
    3. Читай только найденные файлы/функции
    4. Экономь токены - не сканируй весь код
 
## Задача: 
Реализовать пункт {пункт ТЗ} из технического задания на разработку новой функциональности с использованием методологии Test-Driven Development. Важно! Реализуй только данный пункт технического задания!

**Аналитика**:
  1. Техническое задание: {тех. задание}
  2. Пользовательские сценарии для новой функциональности: {сценарии} 

**Алгоритм по TDD**:
  1. Составь минимально необходимый список юнит-тестов, которые покроют реализуемую функциональность. Используй техническое задание и тестовые сценарии для составления тест-кейсов.
  2. Изучи текущую структуру и требования к unit-тестам на основе документации: {test_summary}
  3. Реализуй юнит-тесты для новой функциональности для указанного в задаче пункта из технического задания.
  4. Реализуй указанный в задаче пункт из технического задания.

## Результат:
1. Подготовлены юнит-тесты для разрабатываемой функциональности.
2. Реализована указанный в задаче пункт технического задания
3. юнит-тесты успешно проходят.
